# Small-Scale Rocket Nozzle Expansion Study

## Research Paper
[Open or download the full PDF here](paper/Nozzle_Expansion_Study_v2.pdf)

## Research Question
How does a nozzle expansion ratio proxy affect simulated small-scale rocket performance in OpenRocket?

## Project Overview
This project uses OpenRocket simulations to study how changes in a thrust/expansion-ratio proxy affect apogee, maximum velocity, and flight behavior.

## Tools Used
- OpenRocket
- CSV data table
- Spreadsheet graphing
- GitHub for documentation

## Repository Contents
- `Baseline_Rocket.ork` — OpenRocket design file
- `data/` — raw and/or processed simulation data
- `figures/` — rocket screenshots, motor configuration, simulation results, and graphs

## Important Note
Because OpenRocket does not directly model nozzle expansion ratio changes for this setup, this project used a proxy variable. The results should be interpreted as a simulation-based exploration, not a claim about real nozzle physics.

## Results Summary
Increasing the proxy expansion ratio showed small changes in apogee and maximum velocity. The results suggest that simulation setup, assumptions, and data handling are important parts of aerospace research.

## Limitations
- This was a simulation-only project.
- No physical rocket test was performed.
- The nozzle expansion ratio was represented using a proxy, not direct nozzle geometry.
- Results depend on OpenRocket model assumptions.

## What I Learned
This project helped me learn how to organize a research workflow, document assumptions, preserve raw data, generate figures, and explain simulation results responsibly.
